# AC to DC Converter – PCB Design

## Project Overview
This project demonstrates the design of an AC to DC converter using a Printed Circuit Board (PCB). It converts alternating current (AC) into direct current (DC) for electronic applications.

## Objectives
- Understand AC to DC conversion.
- Design and develop a PCB layout.
- Learn about rectification and filtering.
- Explore basic power electronics concepts.

## Working Principle
1. **AC Input:** Supplies alternating current to the circuit.
2. **Rectification:** Converts AC into pulsating DC using diodes or a bridge rectifier.
3. **Filtering:** Capacitors reduce ripples in the output.
4. **Voltage Regulation:** Provides a stable DC output if a regulator is included.

## Components
- Rectifier diodes or bridge rectifier
- Filter capacitor
- Resistors
- Voltage regulator (if required)
- PCB and connecting terminals

*Note: Actual components depend on the circuit design.*

## Applications
- Electronic power supplies
- Low-voltage electronic circuits
- Embedded system projects
- Educational electronics experiments

## Tools Used
- PCB design software
- Electronic circuit design and layout tools

## Safety
AC mains voltage can cause serious injury or death. Use proper isolation, insulation, and protective measures when testing the circuit.

## Conclusion
This project provides practical experience in PCB design and AC to DC conversion, helping develop fundamental skills in electronics and power supply design.
